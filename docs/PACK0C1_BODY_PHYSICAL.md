# Pack 0C1 — body, physical work and recovery

Internal Stage-I/I.1 engineering slice on merged PR #3, `8337ed130041960331201c495196a9cdafd34357`, branch `pack0c1-body-physical-affordances`. Revision 4.0 remains unchanged and normative. This is a diagnostic execution substrate; no review, agenda, arbitration, autonomous selection, social protocol or Pack 0C2 is present. Autonomous-deliberation counters remain zero. It is not the complete Stage-I scientific gate or the Pack-0 performance gate.

## Implemented ownership and laws

`AdultPhysical` is the authoritative body/resource/work law owner; `TaskRuntime` remains the one six-family execution owner; `GoodsLedger` alone writes containers, sources, consumption sinks and reservations; `EvidenceService` alone writes personal information. Pure body/resource evaluators do not commit on a read. Presentation receives analyst DTOs, while runtime receives immutable evidence-owned `PersonalReview` roots.

Each adult body stores actor identity, M/F class, adult birth time and alive flag; resolved B/A/C/P, display potential and metabolic efficiency; five masteries; five actual post-founding practice totals; condition/wound anchor and held intake/requirement/target/tau/healing; held fatigue/enjoyment; representative activity integrals; leisure satiation and semantic familiarity. The body contains no food inventory. Body accumulation is fed only by the runtime's existing actual paid-prefix cursor; there is no independent body clock paying planned activity.

The resolved capability/mastery profile is a founding input interface. The controlled scenario uses deterministic heterogeneous adults, with ordinary calibrated profiles available for law fixtures. These are explicit resolved inputs, not behavioural professions, inherited genes or simulated childhoods. Stage III can derive the same interface from genotype/development. The canonical 96-founder genotype/development/prehistory distribution and full canonical world are not claimed here. Practice counters describe paid gains since founding; initial mastery is the declared resolved fixture input.

* **Condition (§22.1–22.2):** exact quiet and activity requirement, class and efficiency factors, wound contribution, intake coverage, piecewise target and analytic falling/rising relaxation. Load/intake changes, paid operation boundaries and canonical closures re-anchor. Existing terrain has no designated exposure/protection process; the controlled mild setting contributes zero exposure. The evaluator accepts exposure for a later physical law.
* **Wounds (§22.3):** supplied linear healing at `min(n,1)/2`, clipped at zero. Founding wound input supports controlled tests; there is no injury generator.
* **Fatigue (§22.5):** each semantic-key-staggered closure settles actual effort/rest fractions using the exact target and rise/recovery constants. Debt is held between closures. Movement and extraction apply their declared fatigue factor once; movement inputs refresh at real movement/closure boundaries.
* **Enjoyment (§22.6):** ordinary leisure uses the declared pleasant weight, leisure-family satiation and decaying semantic exposure counts. Closure settles actual pleasant/explicitly declared compulsory union time and exact enjoyment relaxation. An operation counts as an exposure once after paid participation; renaming it does not create a new descriptor. Work supplies no leisure reward, and enjoyment is absent from physical output. Future families can supply pleasant participation to the same closure law.
* **Learning (§24.1–24.4):** competence and task expression stay separate. Five domain shares, held condition/wounds, transfer and useful-work factors form the held learning rate; the closed form commits only paid participation at segment end/interruption/closure. Move uses the declared Field/Organise shares. Updated mastery affects subsequent segments. No passive adult decay, teaching, mentorship or method acquisition is fabricated.

## Generic execution, goods and ecology

`Work` binds a personally known schema to a personally referenced, physically local resource. `extraction.json` carries all four founding extraction records: gather, wood, stone and fibre. One compiled keyed index and one execution path apply the exact weights, class ratios, reference rates, condition/wound exponents, fatigue, metabolic loads and practice shares. Bare-hand equipment/method multipliers and fixture habitat multiplier are one. The path does not branch on extraction method names. Adding 10,000 irrelevant records still costs one selected schema lookup and does not teach a method.

Located resource records hold kind, point, capacity and an analytic stock/demand anchor. Food/wood/fibre renew with the specified capacity/tau; stone is finite. Constant shared extraction uses the joint renewal/demand solution, analytic depletion time and semantic-order symmetric demand shares. No ecology tick, world scan or future renewal advance occurs. A site event materialises only that site and its actual workers. Outputs become ordinary ledger goods in carried containers; cargo stops the paid prefix. Quantized cargo excess remains at the site. Simultaneous finite claims yield the same actor quantities and paid practice under reversed selection order.

`Transfer.use="consume"` establishes a backed, owned local food stream. Existing reservations are reused; automatic backing reserves available real food. Actual elapsed prefixes debit the ledger once and accrue cumulative semantic goods spend. Interruption retains consumed sinks and unused backing; abandonment releases only unused backing. Exhaustion shortens the stream and its final quantized rate agrees with the exact available debit. No body food counter, future harvest funding or displayed-meal debit exists. This slice supports owned custody; claim/agreement authority awaits the existing later rights protocol.

`Recover` supports rest and ordinary leisure at a passable current point (an explicit temporary bivouac, with no protection benefit). It pays ordinary task time. Long Work/Recover survive canonical closures with the same task/purpose, paid cursor, remaining authorization and compact accumulated output. Closure is not task completion. Interrupt/resume cannot refund output or duplicate consumption, rest or practice.

The existing Pack-0A/0B scenarios remain diagnostic substrate fixtures. The explicit `create-body` session command / **Body fixture** button instantiates adults/resources and selects every operation at founding. The chain is finite endowment transfer → gather → real consumption → declared compulsory heavy extraction across closure → rest → separate leisure → later gather. Body signals never insert another step. All seven selected steps complete in the controlled 8/32-person probes.

## Personal information and estimation

Only the existing evidence writer delivers approximate condition (0.05 presentation resolution), intake, wounds, fatigue, enjoyment, own satiation/familiarity and actual practice. Hidden capacities and exact masteries remain analyst/world truth. Starting a backed intake stream delivers experienced intake; operation/closure outcomes deliver dated changes. Own carried goods and reservations continue to use permitted exact self access.

Local site evidence distinguishes durable existence/location/kind from dynamic stock. Stock observations use §11.4 keyed lognormal ecology noise, with private cognitive/Field precision; observed zero is zero, not loss of site existence. Future renewal anchors and demand totals are not delivered. Work delivers observed inventory/output, local stock outcomes and experienced performance.

The evidence-owned rate estimator is deliberately small: separate method/resource-kind contexts; one ordinary cultural prior sample; independent contributions combined in log space with `exp(-age/3)/variance`; latest version only for repeated original provenance. Current context statistics retain anchored weight/log sum/count. Exact historical provenance backing supports replacement without replay or a lifetime current-query scan. `PersonalReview.rateEstimate` ages current sufficient statistics toward the public prior without mutation or truth access. These are noisy contextual realised-performance estimates, not latent competence or a perfect capability oracle. Body forecasting, richer contextual corrections, occupancy/report inference and drive urgency/admission belong to later slices; no estimator selects an action. Tests exercise repeated originals, independent contradictory samples, replacement and age.

## Computational/state contract

Dimensions: N = instantiated adults, C = terrain cells, K = global content, S = real resource sites, W = actual workers sharing the affected site, D = experienced semantic leisure descriptors, Q = experienced rate contexts, H = consequential historical segments. Fixed mastery dimension is five.

| --- | --- | --- | --- |
| Bodies / AdultPhysical | O(N × five + D); fixed body fields, one current integral set per adult, no closure log | O(1) actor lookup; fixed-domain closure, plus copying that person's actual familiarity for a delivered self record; no C/K/population scan | Exact anchors/profile/integrals/exposures persist. Adult lifetime in this slice; Stage-III mortality retirement is deferred |
| Current physical segments / AdultPhysical | At most one per running adult, O(N); ends on real boundary, replaces at closure/resume | Actor map plus dense array slot map; O(1) swap removal, never a scan of other actors | Current held rate, learning, backing and paid-output cursor persist; derived maps rebuild |
| Resources / AdultPhysical | O(S); anchors remain untouched until relevant use/observation | O(1) site lookup; affected-site settlement and rescheduling O(W log W) for canonical ordering plus W actual ledger effects | Actual located sites/stock/demand anchors persist; no site copies per person; no automatic removal/regeneration policy |
| Mastery/practice / AdultPhysical | O(N × five), scalar totals, no lifetime learning list | Fixed five-domain closed-form settlement | Exact totals/masteries persist; work audit is in existing goods/task/paid archives |
| Rate current statistics / EvidenceService | O(Q) genuine personally experienced method/kind contexts | Keyed context/provenance lookup and analytic decay; immutable review uses its existing indexed belief lookup | Current anchored sufficient statistics persist; no lifetime scan on an estimate |
| Rate original backing / EvidenceService | O(H) distinct actual originals, explicitly cold historical backing | Direct original-key replacement only; never enumerated by ordinary execution or review | Exact backing retained in checkpoint. | Ledger/runtime/evidence extensions | Existing current task, reservation and bounded place/review policies; fixed compact output per step | Existing direct current-task/carried/reservation and evidence indexes | Existing consequential transactions, paid prefixes, semantic spend/retry and terminal history grow honestly; none is replayed to compute body state |
| Extraction index / content | O(K) startup compilation, shared thereafter | One keyed selected-method read; catalogue extension changes startup cost only | Content identity is persisted, index reconstructed; globally installed records never imply personal acquisition |
| Analyst/counters | Non-causal measurement; counters never drive a law | Explicit full snapshots/checkpoints may still serialize the world/history, inherited pre-0C cost | Counters excluded from causal state. Full serialization/publication optimization remains an existing proof-gate obligation |

All physiological, ecological, class, task and learning coefficients use the specified scientific values. Existing time quantum and staggered closure are N values. Maps, slot arrays, compilation and instrumentation are implementation choices, not scientific workload caps. Familiarity's place-block descriptor is semantic; it cannot be reset by a display name. No memory policy evicts necessary original backing to hit a performance target.

Dense worst case: a join/leave/closure at a truly shared site can affect all W workers. N same-site closures can therefore require quadratic affected-worker work across the interval; this is reported, not hidden with a neighbour cap. Sparse independent sites incur fixed actor/site work. There is no N×C or ordinary K scan. Whole checkpoints retain inherited terrain and historical costs; this is not a constant-total-memory or mature-performance claim.
