## State and access boundaries

Previously `TaskRuntime.task()` copied and reversed the lifetime task array; selection scanned old tasks and timed-step continuation filtered lifetime paid prefixes. Now `tasks` holds only active/blocked/suspended tasks, with direct actor/id/routing maps. `paidForStep`, `active.paidThrough`, cumulative semantic spend and current calendar totals suffice for continuation. Terminal full execution objects and paid prefixes move to separate audit arrays; indexed retry, original-purpose authorisation, issued identities and latest-terminal references retain exact accountability. Representative closure archives settled calendar totals without resetting a live task or its spend. `currentExecution()` never consults a terminal task. The explicitly requested inspector can show the indexed last terminal task. Archive storage still resides in memory and complete checkpoints still include it; constant total resident memory is not claimed.

`PersonalReview` captures immutable belief/property/region/known-method/route index roots and a geography version, plus detached permitted exact self facts. Belief/context/version, bounded property/resource/region posting, method-effect, canonical-route and cell/page reads share stable premises. Cursors use deterministic ordered keys, with a bounded lookahead for the next page. Exact self includes only carried backing and active own reservations. `MethodIndex` compiles id/effect/input postings globally; it does not acquire methods for anyone. The personal method posting contains only delivered known methods. Existing `PersonalView` and Personal Lens remain explicit bulk inspection/export, and runtime execution uses the narrow interface.

Delivered geometry creates an immutable sparse AVL root by replacing affected paths, cell values and affected survey provenance. Searches pin versions, never truth arrays or a copied full personal map. Current and pinned roots share immutable values/pages in memory. Connected personal region topology retains the inherited epistemic semantics and is cached per version/profile; its first construction is still O(V). Old versions survive active search and exact incomplete retry scopes. Pin reference counts and direct slot removal release unreferenced version backing; live review references remain valid. Cold restore rebuilds derived current indexes; persisted pinned roots are normalized for storage/hash so accelerator tree shape and removal order cannot become causal identity.

Personal search retains only discovered cell/coarse frontier nodes and persisted heap arrays. Warm resumes reuse heaps; cold restore uses already-valid heap order without reheapifying. Host slices count all heap pops, including stale entries. Instrumentation separately reports cell/region expansions, cell index nodes consulted, region records, heap pushes/pops/rebuilds, geography copied and host resumes. Regional guidance is measured overhead; the existing N rule charges **cell** expansions, not an invented regional unit cost.

The diagnostic effort adapter admits a caller-owned account using §47's review 600 / safety 80 / repair 40 EU and route 1 EU per 64 cell expansions. Partially paid blocks are retained exactly. Repeated searches/tasks at the same diagnostic causal boundary share spend; host resume, renaming, interruption and restore cannot renew it. Exhaustion retains the frontier, leaves status routing with explicit computational deferral, and publishes no route impossibility, evidence or repair failure. A later explicitly admitted diagnostic boundary can resume; it does not implement review scheduling, review caps, objective choice or a free-budget policy for the future mind. Known personal-graph exhaustion remains an epistemic no-route result. Host yields advance no causal time. Future cognition must pass its already-admitted account through all nested work.

Canonical remembered route identity depends on the ordered cell path, independent of task purpose. Current dated/versioned route knowledge is updated; every observed journey is separately appended with its task/path/status/date in consequential history. Active task geometry/dependencies remain separate, and local delivered blockage still invalidates the affected execution. Distinct genuinely learned paths may grow; no arbitrary route forgetting limit is added.

GoodsLedger retains one authoritative quantity. Derived carried-container, good-by-id, actor-active-reservation and container/good-active-reservation indexes reference that authority. Spent/released/expired reservations leave active indexes, while original records remain audit backing. Actual carried goods/active reservations can legitimately enlarge self reads.
